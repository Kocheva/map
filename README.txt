КАРТА ПРОЕКТНЫХ ЛИДЕРОВ И СООБЩЕСТВ

Это готовая статическая версия сайта. Устанавливать Node.js, Python или базу
данных на хостинге не требуется.

ОБЫЧНЫЙ ХОСТИНГ
1. Распакуйте ZIP.
2. Загрузите ВСЕ файлы и папки из архива в корневую папку сайта.
3. Убедитесь, что index.html находится в корне, рядом с папками assets и data.

GITHUB PAGES
1. Создайте новый репозиторий GitHub.
2. Загрузите в корень репозитория ВСЕ файлы и папки из архива.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку main, папку /(root) и нажмите Save.
6. Через несколько минут GitHub покажет опубликованный адрес.

ЛОКАЛЬНЫЙ ПРОСМОТР
Двойной клик по index.html может не загрузить данные из-за ограничений браузера.
Для локального просмотра запустите в этой папке простой HTTP-сервер, например:

  python -m http.server 8000

После этого откройте http://localhost:8000

ВАЖНО
- Не переименовывайте и не удаляйте папки assets и data.
- Исходная Excel-книга находится в папке data.
- Сайт не использует серверную базу данных и внешние библиотеки.
