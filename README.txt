КАРТА ПРОЕКТНЫХ ЛИДЕРОВ И СООБЩЕСТВ — 21.09.2026

Готовый статический сайт для GitHub Pages и обычного хостинга.
Загрузите index.html, папки assets и data и остальные файлы из архива.
Сборка и серверная база данных не требуются.

ПРИ ОБНОВЛЕНИИ
Замените файлы сайта. Удалите из папки data на хостинге прежние XLSX-файлы:
leaders_map_updated.xlsx и, если остался, leaders_map_dashboard_8_regions_final.xlsx.
В текущем архиве папка data содержит только leaders.json. Кнопки скачивания нет.
После загрузки обновите страницу через Ctrl+F5.

СОДЕРЖАНИЕ
584 персоны, 144 руководителя проектов фонда, 209 записей о проектах.
Конкурсы сгруппированы по названиям, независимо от года и этапа:
- Время действовать (2025) — 6 проектов;
- Добрый спорт (2024–2025) — 16;
- Сила внимания (2023–2026) — 39;
- Среда возможностей (2023–2026) — 98;
- Туда, где семья (2023–2026) — 45;
- Территории тепла (2023) — 5.
Числа обозначают записи о проектах, включая отдельные этапы поддержки,
и не меняются при выборе других фильтров. Результаты карты считают людей.
Период отражает годы, указанные в названиях этапов и годах конкурсов реестра.
Детальные названия и сроки сохранены в карточках. Исходный JSON не изменён.

ФИЛЬТРЫ
Внутри группы действует «любое из выбранных», между группами — пересечение.
Старые ссылки с идентификатором отдельного года конкурса открывают всю группу.
На широких экранах — четыре блока; на средних — два столбца; на телефоне — один.

РЕДАКТИРОВАНИЕ
assets/site-config.js — адреса Библиотеки, Фонда Тимченко и Центра ГРАНИ.
assets/content.js — методология, источники, футер и навигация.
assets/app.js — карта, фильтры и карточки.
assets/project.css — оформление в стиле Библиотеки организатора.
assets/background.jpg — исходная иллюстрация с лампочками.
data/leaders.json — данные сайта.

ПРОВЕРЕНО
Шесть групп конкурсов, числа проектов и людей, множественный выбор,
пересечение с регионом, сброс, старые ссылки, перезагрузка, методология,
четыре блока на широком экране, мобильная вёрстка, отсутствие кнопки скачивания.

ЛОКАЛЬНЫЙ ПРОСМОТР
Из папки сайта: python -m http.server 8000
Откройте http://localhost:8000. Двойной клик по index.html не подходит из-за
браузерных ограничений загрузки JSON и модулей.
